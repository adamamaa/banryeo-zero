## ④ 검증 및 한계 대응

**AI 답변 검증:** 숫자 비교와 자격 판정은 AI가 아니라 서버 코드가 한다. 원가구·독립 특례 같은 대체 경로와 공고에 적힌 근로소득 공제도 서버가 계산한다. 공식 원문, 웹 검색, 첨부 공고로 뒷받침되지 않는 조건은 판정에서 빼고 추가 확인으로 안내한다. 답변을 내기 전에 계산 수치·판정 일치·지난 마감일·확정 표현·공식 원문·링크를 자동 점검하고, 문제가 있으면 다시 쓰게 한다. 프롬프트에는 요청마다 한국 시간 기준 오늘 날짜를 넣는다.

**데이터 검증:** 온통청년 정책 600건을 조회해 기간이 지정된 290건 중 48건이 신청기간 300일 이상, 41건이 사업기간과 같음을 확인하고, 이런 기간은 마감일로 표시하지 않게 했다. 국민취업지원제도 구직촉진수당 금액이 기록별로 다른 사례를 확인해 금액 대조에 반영했다(2026. 11. 18. 직접 조회).

**실행 검증:** 공공 API 3종 실제 호출, 가상 서류의 주소·성명·전입일 문제 탐지, 생성한 엑셀·워드 파일 열람, TypeScript 타입 검사를 했다. 배포 사이트는 로그인 정보가 없는 새 브라우저에서 확인했다(2026. 11. 19.). 요청마다 Gemini 호출 수·토큰·예상 비용을 기록해 비용을 점검한다.

**개인정보:** 이름·연락처는 받지 않고 내 정보는 브라우저에만 저장한다. 질문하면 조건이 Gemini로 간다는 사실을 화면에 안내하고, 체험용 가상 서류를 화면에서 받게 했다. 텍스트는 주민등록번호(하이픈 없는 형태 포함)·휴대전화·계좌번호를 가린 뒤 보낸다.

**남은 한계:** 최종 자격 판단은 접수 기관이 하므로 화면에 안내한다. 이름·주소와 이미지·PDF 원본은 가리지 못해 개발·시연에는 가상 서류만 쓴다. 여러 도구를 쓰는 질문은 답변까지 수 분이 걸릴 수 있다. 시연영상은 실제 서비스 화면에 리허설에서 받은 실제 AI 응답을 재생해 구성했다.
