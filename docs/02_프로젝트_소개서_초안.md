## 1. 표지

- **반려제로** — 신청 전에, 떨어질 이유부터 찾아 주는 청년 지원금 사전 점검 에이전트
- 2026 대한민국 청년 CAREER FAIR AI 해커톤 / 주제: AI 에이전트로 푸는 청년의 일·생활 문제
- 팀명 【확인】 · 프로토타입 https://gonggo-pass.vercel.app/ · 저장소 https://github.com/adamamaa/gonggo-pass
- 넣을 화면: 첫 화면 ("신청 전에, 떨어질 이유부터 찾아드려요")

## 2. 문제 정의: 받을 수 있는 돈인데 왜 포기할까

**핵심 메시지:** 청년이 지원금을 포기하는 이유는 정보 부족이 아니라, 제출하고 2주 뒤에야 반려를 알게 되는 구조가 헛수고의 위험을 청년에게 모두 떠넘기기 때문이다.

1. 공고문을 읽을수록 '받을 수 있다'는 확신은 줄고 할 일만 늘어난다.
2. 공고문은 본문·별표·주석에 탈락 조건("단, ~인 경우 제외")을 흩어 놓은 조건문 미로다.
3. 청년이 아는 '일상의 나'와 공고가 요구하는 '행정 데이터의 나'가 달라, 서류를 다 떼어 보기 전에는 자격조차 모른다.
4. 심사는 사후 판정이라, 반차를 내고 서류를 떼도 옵션 하나를 놓치면 0원이 된다.

- 근거 데이터: 온통청년 정책 600건 중 기간이 지정된 290건의 48건이 신청기간 300일 이상, 41건이 사업기간과 같음 (2026-11-18 직접 조회). 공공 데이터만 봐서는 실제 마감일도 알기 어렵다.
- 【확인: 반려·미신청 관련 공식 통계나 설문이 있으면 출처와 함께 추가】

## 3. 대상 사용자와 대표 시나리오

- 대상: 월세·구직 지원을 처음 신청하는 만 19~34세 청년, 행정 용어에 익숙하지 않은 사람
- 시나리오 A (주거): 청년월세 지원 — 원가구·독립가구 조건, 등본·임대차계약서·확정일자 교차 검증
- 시나리오 B (일·구직): 국민취업지원제도 구직촉진수당 — 가구 소득 판독, 취업활동계획서 초안
- 시나리오 C (지역): 대구 월세 세트 — 지역 공고와 중개보수 영수증까지 점검
- 【확인: 영상·발표에서 실제로 보여 줄 시나리오만 남기기】

## 4. 반려제로가 하는 일

**핵심 메시지:** 공고 찾기부터 자격 확인, 서류 검수, 제출 준비 파일까지 한 대화 안에서 끝낸다.

1. **추천 공고:** 온통청년·복지로·보조금24에서 내 지역·상황·관심 분야와 관련 있는 공고만, 마감이 확인된 공고부터 보여 준다.
2. **자격 확인:** 공고 조건과 내 정보를 서버가 대조해 충족·미충족·추가 확인을 나눈다.
3. **금액 대조:** 답변의 금액을 가장 최근 수정된 공식 원문과 비교한다.
4. **서류 검수:** 올린 서류의 누락, 발급일, 성명·주소 일치, 직인을 점검하고 보완 방법을 알려 준다.
5. **제출 준비:** 체크리스트, 소명서·사유서 초안, 엑셀·워드·캘린더 파일을 만든다.
6. **안 될 때 대안:** 자격이 안 되면 이유와 함께 대신 받을 수 있는 지원을 실제 공고에서 찾는다.

- 넣을 화면: 질문 → 실행 계획 → 도구 실행 단계 → 근거 카드가 이어지는 한 장면

## 5. 왜 AI 에이전트인가, 어떻게 쓰나

**핵심 메시지:** 공고마다 조건 구조가 달라 고정 규칙으로는 못 푼다. AI는 공고를 읽고 필요한 도구를 고르고, 판정은 서버 코드가 한다.

- **왜 AI인가:** 공고문의 별표·단서 조항을 해석하고, 사진으로 찍은 서류를 읽고, 사용자의 일상 언어를 행정 조건으로 바꾸는 일은 규칙 코드로 만들 수 없다.
- **어떻게 쓰나:** Gemini가 먼저 2~5단계 실행 계획을 세우고, Function Calling으로 도구를 골라 실행한다.
  - 도구 예: 공고 검색, 공식 원문 확인, 자격 판정, 서류 검수, 대안 찾기, 체크리스트·초안·파일 생성, 사용자에게 한 가지 되묻기
- **추론 수준 선택:** 질문마다 난이도를 먼저 판단해 일반 안내는 medium, 법령·예외 조항·서류 해석은 high로 처리한다.
- 넣을 화면: 실행 계획 패널, 도구 실행 기록

## 6. AI가 실제로 기여하는 곳

**핵심 메시지:** AI가 없으면 사람이 30쪽 공고와 서류 7장을 직접 대조해야 하는 일을 대신한다.

- **서류 판독(멀티모달):** 등본·계약서 이미지에서 주소, 전입일, 확정일자, 발급일, 직인을 읽는다.
  - 예: 가상 세트 A에서 등본 301호와 계약서 302호의 불일치, 확정일자 누락, 전입일 미표시를 찾아낸다.
- **공고 조건 → 일상 질문:** 공고문을 올리면 숨은 예외·특례 조건을 "부모님과 따로 산 지 1년이 넘었나요?" 같은 질문으로 바꾼다.
- **대안 탐색:** 안 되는 이유를 밝히고, 사용자가 원래 이루려던 목적에 맞는 다른 지원을 찾는다.
- **결과물 작성:** 소명서·사유서·계획서 초안과 제출 직전 체크리스트를 만든다.
- 넣을 화면: 서류 검수 리포트(통과·반려 위험 배지와 보완 방법)

## 7. 틀릴 수 있는 AI를 어떻게 막나

**핵심 메시지:** AI는 해석과 도구 선택만 맡고, 숫자와 판정은 서버가 하고, 답변은 내보내기 전에 한 번 더 점검한다.

| 위험 | 대응 |
| :--- | :--- |
| 숫자·자격을 잘못 계산 | 서버 코드가 계산 (대체 경로, 근로소득 공제, 기준 중위소득) |
| 근거 없는 조건을 지어냄 | 공식 원문·검색·첨부 공고로 확인된 조건만 판정에 사용 |
| 오래된 금액 안내 | 최신 공식 원문과 금액 대조 |
| 지난 마감을 신청 가능처럼 안내 | 오늘 날짜(한국 시간)를 프롬프트에 넣고, 답변에서 지난 날짜를 점검 |
| 단정 표현, 비공식 링크 | 답변 자동 점검 후 다시 쓰기, 공식·등록 사이트 링크만 표시 |
| 서류를 못 읽음 | "판독 불가"로 표시, 추측 금지 |
| 개인정보 | 텍스트 마스킹, 브라우저 저장, 전송 사실 안내, 시연은 가상 데이터만 |

- 모든 도구 결과에 출처 배지(실계산 / 예시 데이터 / 실시간 API)를 붙인다.
- 최종 판정은 접수 기관이 한다고 화면에 안내한다.
- 넣을 화면: 답변 검증 단계, 출처 배지

## 8. 기존 서비스와 무엇이 다른가

| 구분 | 온통청년·보조금24 | 일반 정책 챗봇 | 반려제로 |
| :--- | :--- | :--- | :--- |
| 핵심 역할 | 공고 게시판 | 공고 요약 Q&A | 자격 확정 + 서류 검수 + 제출 준비 |
| 자격 판독 | 나이·지역 필터 | 본문 요약 (별표 예외 누락) | 별표·단서 조건까지 서버가 판정 |
| 서류 준비 | "공고문 참고" | 서류 이름 나열 | 내 상황 맞춤 서류, 발급처 안내 |
| 반려 방어 | 없음 | 없음 | 제출 전 서류 교차 검증 |
| 안 될 때 | 없음 | 없음 | 이유 + 대안 지원 제시 |
| 결과물 | 상세 페이지 링크 | 채팅 텍스트 | 체크리스트, 초안, 엑셀·워드·캘린더 파일 |

## 9. 구현 구조와 실제 동작 범위

- **구조:** Next.js 화면 → `/api/agent/run` 서버 → Gemini(Function Calling, Google Search) + 공공 API 3종(온통청년, 보조금24, 복지로) → 서버 판정 코드(자격, 금액, 마감) → 답변 점검 → 화면
- **배포:** Vercel, 로그인 없이 접속 가능
- **동작 범위 (정직한 구분):**

| 구분 | 내용 |
| :--- | :--- |
| 실제 계산 | 기준 중위소득 비율, 대체 경로·근로소득 공제 판정, 보증금 월세 환산, 마감일 판정, 개인정보 마스킹 |
| 실시간 API | 온통청년·보조금24·복지로 공고 조회, 공식 원문 확인, Gemini 판독·답변 |
| 예시 데이터 | 시연용 가상 서류와 가상 공고문 |
| 미구현 | 정부24 서류 발급 연동, 실제 신청서 서식 파일 생성 【확인: 최신 기준으로 다시 확인】 |

- 넣을 화면: 구조도 한 장

## 10. 비용·운영과 확장 계획

**핵심 메시지:** 요청마다 비용을 기록하고 있어서, 확대할 때 품질과 비용을 숫자로 관리할 수 있다.

- **비용:** 요청마다 Gemini 호출 수, 토큰, 예상 비용을 기록한다. 난이도 판단은 가장 낮은 추론 수준으로 빠르게 하고, 일반 안내는 medium, 어려운 해석만 high로 처리해 비용을 줄인다.
  - 【확인: 시연 시나리오별 실제 요청당 비용(USD) 기록값 추가】
- **운영:** 사용자 정보를 서버에 저장하지 않아 DB·보안 운영 부담이 작다. 공공 API 키와 Gemini 사용량 한도만 관리하면 된다.
- **확장:**
  1. 임의 공고문을 올리면 조건 규칙을 자동으로 뽑아 바로 판정
  2. 정부24·홈택스 서류 발급 안내를 실제 연동으로 확대
  3. 반려가 잦은 서류 규격을 모아 검수 규칙을 늘림
  4. 지자체·대학 상담 창구용 버전(상담사가 함께 보는 화면)
- **품질·비용 발전 방안:** 자주 묻는 정책의 공식 원문을 캐시해 검색 비용을 줄이고, 답변 점검에서 걸린 유형을 모아 프롬프트와 규칙을 고친다.
