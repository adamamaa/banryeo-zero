## 제출 방법

입력란별로 넣을 것과 메일 초안은 [제출/README.md](제출/README.md)에 한 장으로 정리했다.


- 과제 제출 링크(참가 신청 후 팀 대표자에게 발송)에 올리고, 같은 자료를 대회 안내문의 운영사무국 메일로도 보낸다.
- 파일명: `[팀명]_프로젝트명_AI 해커톤_제출일자`
- 메일 제목: 파일명 뒤에 ` / 과제제출`
