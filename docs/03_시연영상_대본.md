# 시연영상 대본 초안 (3분 이내, 선택 제출물)

> 실제 서비스 화면(https://banryeo-zero.vercel.app/)과 실제 AI 응답으로 촬영한다. 미리 저장한 결과를 재생하지 않는다. AI 답변은 30~60초 걸리므로 기다리는 구간만 편집으로 줄이고, 줄였다는 자막을 넣는다.
>
> 입력은 가상 프로필, 서류는 `public/sample-docs/C_대구시연세트`(가상 서류 3건)만 쓴다. 인스타그램은 실제 공개 릴스 링크를 쓴다. API 키, `.env.local`, 브라우저 주소창의 개인 정보가 화면에 나오지 않게 한다.
>
> 소개서 4장의 핵심 기능 7개(Must 3·Should 2·매력 2)와 같은 순서로 보여 준다. 「AI 활용내역」·소개서 6장과 같은 시연 서류(대구 세트 C)를 쓴다.

**가상 프로필:** 대구 수성구, 만 27세, 구직 중, 월 소득 0원, 부모님과 따로 산 지 8개월, 월세(보증금 1,000만 원 / 월세 50만 원), 무주택, 미혼 — 세트 C 서류(1999년생 김청년, 2026-03-02 계약)와 맞춘 값

**세트 C에서 찾아야 할 반려 위험:** 등본 301호 / 계약서·영수증 302호, 영수증 지급인 김철수 / 신청자 김청년, 등본 전입일 미표시, 계약서 확정일자 없음

**인스타그램 링크:** `https://www.instagram.com/reel/De0ixlMBub4/` (2026 청년정책 공모전 안내 릴스, 접수 10-30 마감). 2026-11-20 공개 사이트에서 "10.30 이미 마감돼 신청 불가"로 답하는 것을 확인했다.
