# 시연영상 대본 초안 (3분 이내, 선택 제출물)

> 실제 서비스 화면으로 촬영한다. 입력은 가상 프로필, 서류는 `public/sample-docs`의 가상 세트만 쓴다. API 키, `.env.local`, 브라우저 주소창의 개인 정보가 화면에 나오지 않게 한다.
>
> 【확인: 이미 만든 영상 구성이나 리허설 응답이 있으면 그것을 기준으로 이 표를 고친다】

**가상 프로필 예시:** 서울 관악구, 만 27세, 구직 중, 월 소득 0원, 부모님과 따로 산 지 15개월, 월세(보증금 1,000만 원 / 월세 75만 원), 무주택, 미혼 — 세트 A·B 서류(1999년생 김청년, 2025-08-20 계약)와 맞춘 값

| 시간 | 화면 | 내레이션 | 자막 |
| :--- | :--- | :--- | :--- |
| 0:00–0:15 | 30쪽 공고문을 스크롤하다 멈추는 장면 → 반려제로 첫 화면 | "받을 수 있는 지원금인데, 공고문을 읽다가 포기한 적 있으신가요? 서류를 다 내고 2주 뒤에 반려되면, 그 시간은 그냥 사라집니다." | 신청 전에, 떨어질 이유부터 |
| 0:15–0:30 | 내 정보 입력 (태그 선택) → 추천 공고 목록 | "몇 가지 조건만 고르면, 내 지역과 상황에 맞는 공고를 마감이 확인된 것부터 보여 줍니다." | 가상 프로필로 시연합니다 |
| 0:30–1:05 | "청년월세 지원 받을 수 있어?" 질문 → 실행 계획 → 도구 실행 단계 → 근거 카드 | "AI가 먼저 계획을 세우고, 공식 원문을 확인하고, 자격은 서버가 계산합니다. 금액은 최신 공식 원문과 대조합니다." | AI 생성 응답 · 판정은 서버 계산 |
| 1:05–1:45 | 세트 A(반려 위험) 업로드 → 서류 검수 리포트 | "서류를 올리면 AI가 읽고 교차 검증합니다. 등본은 301호, 계약서는 302호. 확정일자도 없고 전입일도 빠졌습니다. 제출했다면 반려됐을 서류입니다." | 반려 위험 3건 적발 |
| 1:45–2:10 | 세트 B(보완 완료) 업로드 → 통과 → 제출 직전 체크리스트, 소명서 초안 | "보완한 서류는 통과. 제출 직전 체크리스트와, 필요하면 소명서 초안까지 만들어 줍니다." | 검수 → 실행까지 |
| 2:10–2:35 | 자격이 안 되는 질문 → 안 되는 이유 + 대안 지원 카드 | "안 된다는 답에서 멈추지 않습니다. 왜 안 되는지 밝히고, 대신 받을 수 있는 지원을 실제 공고에서 찾습니다." | 안 되면 대안까지 |
| 2:35–2:55 | 답변 검증 단계, 출처 배지, "최종 판정은 접수 기관" 안내 | "AI는 해석과 도구 선택을 맡고, 숫자와 판정은 서버가, 답변은 내보내기 전에 한 번 더 점검합니다." | 틀릴 수 있는 AI를 막는 장치 |
| 2:55–3:00 | 첫 화면 + 프로토타입 주소 | "반려제로. 신청 전에, 떨어질 이유부터 찾아드립니다." | gonggo-pass.vercel.app |

**촬영 체크**

- [ ] 총 길이 3:00 이내
- [ ] AI 생성 응답임을 보여 주는 장면 1회 이상 (0:30–1:05 자막)
- [ ] 실제 개인정보, API 키, 사용량 대시보드가 화면에 없음
- [ ] 리허설 응답을 재생해 구성했다면 「AI 활용내역」 ④에 적은 내용과 일치
- [ ] 배경음·효과음 출처를 별첨 「활용한 외부 자원·출처」에 기재
