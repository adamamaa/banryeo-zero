## 정해진 것 (바꾸지 말 것)

- **이미지·PDF 서류는 원본이 Gemini로 전송된다.** 문서에는 실제 동작대로 적고, 전송 전 마스킹은 확장 계획(추후 발전)으로만 쓴다. "OCR로 가린 뒤 전송"처럼 쓰면 허위 기재다.
- **팀은 3인(리더 1명, 팀원 2명).** 이름은 공개 저장소에 넣지 않고 소개서 PDF·제출 설문에만 쓴다.
- **기존 개발물: 해당 없음.** 2026-11-16 개발 시작, MVP 첫 버전은 Antigravity로 만들어 같은 날 첫 커밋.
- **개발 AI 도구:** Claude(규칙 분석·자료조사·QA·문서), ChatGPT(자료조사), Claude Code 2.1.220(Opus 5.5·Fable 5.2, 코드 대부분), Antigravity 2.32.1(Gemini 4 Argon·Hydrogen, MVP·가벼운 버그 수정), Stitch 2.0(화면 디자인), Nano Banana(로고 생성), Neon(로고 SVG 변환, Google AI 모델). 서비스 AI: Gemini API(gemini-4-hydrogen) + 내장 Google 검색.
- **로고는 AI 생성**(Nano Banana, Neon) → 별첨에 "AI 생성 + 도구명"으로 기재 완료.
- **인스타그램 링크는 캡션과 대본(텍스트)만 받는다.** 영상·이미지는 받지도 분석하지도 않는다. 대본은 ScrapeCreators가 음성 인식으로 만든 텍스트다. 시연은 미리 저장한 결과가 아니라 실제 릴스로 한다.
- **시연 서류는 대구 세트 C**(등본 301호/계약서 302호, 김청년/영수증 김철수, 전입일 미표시, 확정일자 없음). 「AI 활용내역」·소개서·영상 대본이 모두 이 세트를 쓴다.
- **소개서 기능은 7개**(Must: 맞춤 공고·자격 판정·서류 검수 / Should: 공식 원문 대조·제출 준비 / 매력: 대안 추천·공고문과 인스타 게시물 검증).

## 작업 규칙

- **문서를 쓸 때는 코드와 대조한다.** 팀원 문서도 코드 사실과 다르면 고치고, 고친 곳을 문서 머리말에 남긴다.
- **「AI 활용내역」은 3,000자 제한이 빠듯하다.** 문장을 더하면 겹치는 문장을 빼고, 줄바꿈 2자 기준으로도 3,000자 이하인지 센다.
- **외부 AI에 실제 개인정보를 넣지 않는다.** 시연·테스트는 `public/sample-docs`의 가상 서류만 쓴다.
- **API 키는 저장소에 올리지 않는다.** `.gitignore`가 모든 `.env` 파일을 막는다. 키는 로컬 `.env.local`과 Vercel 환경변수에만 둔다 (`GEMINI_API_KEY`, `PUBLIC_DATA_API_KEY`, `YOUTHCENTER_API_KEY`, `TREG_API_KEY`).
- **이 PC에서 Node 실행:** node·npm이 PATH에 없다. `ELECTRON_RUN_AS_NODE=1`로 `C:\Users\user\AppData\Local\Programs\antigravity\Antigravity.exe`를 node처럼 쓴다(예: `node_modules\typescript\bin\tsc --noEmit -p .`). 로컬 서버는 `실행하기.bat`(포트 3000). 이미 떠 있으면 두 번째 서버를 띄우지 않는다(`.next`를 같이 써서 꼬임).
