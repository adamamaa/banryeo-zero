# 공고패스 (GongGoPass)

청년 지원금 신청 서류를 **제출 전에** 점검하는 도우미. 공고문 조건으로 자격을 계산하고, 준비한 서류를 접수 기준에 맞춰 검수한다.

2026 대한민국 청년 CAREER FAIR AI 해커톤 출품작 (1인 개발 MVP). 대상 공고: 청년월세 한시 특별지원.

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 (Windows는 `실행하기.bat` 더블클릭)

## 무엇이 실제로 동작하나

화면의 모든 결과에는 출처 배지가 붙는다.

| 배지 | 의미 | 해당 기능 |
| --- | --- | --- |
| 실계산 | 입력값으로 실제 계산 | 중위소득 비율, 보증금 월세 환산, 특례 판정, 개인정보 마스킹, 계획서 금칙어 점검 |
| 예시 데이터 | 시연용 데이터 | 공고문 조항, 건축물대장, 시연 서류 세트 A/B |
| 실시간 API | 외부 API 응답 | 보조금24 조회 (공공데이터포털 키 입력 시) |

- **키 없이**: 자격 계산 전체, 텍스트(.txt) 서류 규칙 검수.
- **Gemini 키 입력 시**: 이미지·PDF 서류 판독, 자유 질문 답변. 좌측 하단 `API 설정` 또는 `.env.local`의 `GEMINI_API_KEY`.

## 시연 순서

1. **자격 판정**: 26세, 월 130만 원, 보증금 1,000만 / 월세 75만. 본문만 보면 월세 70만 원 초과로 탈락처럼 보이지만 환산 합산 795,833원(상한 90만 원)과 독립가구 특례로 대상. 우측 `실행 내역`에서 값을 바꿔 다시 계산 가능.
2. **발급 가이드**: 필요한 서류 4종과 발급 시 선택할 옵션.
3. **사전 검수**: 예시 세트 A에서 반려 위험 4건 적발.
4. **재검수 · 신청 패키지**: 세트 B 통과, 신청서 기입과 계획서 점검.

**직접 업로드 시연**: `public/sample-docs/A_미비세트`의 파일 3개를 첨부하면 내용 기반 규칙 검수로 위험 5건을 찾는다. `B_보완세트`는 0건.

## 검증

```bash
node scripts/smoke.mjs
```

개발 서버가 떠 있을 때 실행. 기준 수치와 규칙 검수 결과를 확인한다.

## 구조

- `src/app/page.tsx` 화면
- `src/app/api/agent/execute` 도구 체인 실행
- `src/app/api/agent/run` 서류 검수, 질문 답변, 키 확인
- `src/lib/standards.ts` 2026년 기준 중위소득 등 기준 수치 (한 곳에서 관리)
- `src/lib/docRules.ts` 텍스트 서류 규칙 검수 엔진
- `src/lib/tools.ts` 도구 9개와 출처 표시
- `src/data/policies.ts` 시연용 공고문·서류 데이터

## 한계

- 공고문 조항과 페이지 번호는 시연용으로 구성한 것이며 실제 공고문과 다를 수 있다.
- 사전 점검 결과일 뿐 최종 판정은 접수 기관이 한다.
- 이미지·PDF 서류는 판독을 위해 원본이 Gemini로 전송된다. 텍스트 서류만 마스킹 후 전송된다.
