# 🛡️ 공고패스 (GongGoPass) — 청년 지원금 사전 모의심사 & 서류 완주 에이전트

> **2026 대한민국 청년 CAREER FAIR AI 해커톤 출품작 (1인 개발 MVP)**  
> *"왜 청년들은 받을 수 있는 돈인데도 공고문을 읽다가 포기할까?"*  
> 30페이지 공고문의 숨은 별표 조건을 **‘일상 질문 3~4개’**로 판독해 받을 돈부터 확정해 주고, 제출 전 **‘AI 공무원 사전 모의심사’**로 서류 반려(헛수고) 확률을 0%로 만드는 청년 행정 완주 에이전트입니다.

---

## 🚀 로컬 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서버 실행 (http://localhost:3000)
npm run dev
```

* 별도의 API Key 설정 없이도 내장된 **Rule-Tree 조건문 컴파일러**와 **다중 서류 교차검증 엔진**으로 전체 4단계 시연이 100% 작동합니다.
* 상단 우측의 **`[직접 공고문 입력 / Gemini API 설정]`** 버튼을 눌러 `GEMINI_API_KEY`를 입력하면 `Gemini 2.5 Flash` 실시간 멀티모달 분석 모드로도 동작합니다.

## 🎯 핵심 4단계 에이전트 파이프라인 (시연 가이드)

1. **[Step 1] 서류 0장! 일상 언어 역질문 & 별표 특례 역추론 (`Why 2·3 해결`)**
   * **시연 포인트**: 상단에서 `김청년(26세·자취 알바생)` 프리셋을 클릭합니다.
   * 본문 8p만 읽으면 부모님 소득 초과 및 월세 70만 원 초과로 포기할 케이스지만, 에이전트가 **3p 보증금 환산액 단서조항**과 **18p `[별표2]` 청년 독립가구 단독산정 특례**를 동시에 찾아내어 **총 240만 원 100% 수급 가능** 판정을 내립니다.
2. **[Step 2] 내 맞춤 서류 장바구니 & 정부24 체크박스 정답지 (`Why 3 해결`)**
   * **시연 포인트**: 공고문에 적힌 12개 서류 중 특례 적용으로 불필요한 8개 서류를 자동 소거하고, 필수 서류 4개에 대해 **정부24 발급 시 절대 틀리면 안 되는 체크박스 옵션 정답지**를 제시합니다.
3. **[Step 3] 🔥 AI 공무원 사전 모의심사 스튜디오 (`Why 4 해결 — 킬러 데모`)**
   * **시연 포인트**:
     * **`🔴 시연 A (실수/누락 있는 서류 세트)`**: 등본 전입일 옵션 미체크, 등본 호수(301호)와 계약서 호수(302호) 불일치, 계약서 확정일자 직인 누락, 가족관계증명서 '일반' 오발급 등 **4대 반려 사유를 빨간펜 첨삭과 교차검증 매트릭스로 3초 만에 적발**합니다.
     * **`🟢 시연 B (보완 완료 서류 세트)`**: 보완 후 **사전 심사 통과 확률 15% → 99% 전환**을 시연합니다.
     * **`📤 내 서류 직접 업로드`**: `public/sample-docs/` 폴더 안의 샘플 파일(`주민등록등본_전입일누락_미비샘플.txt` vs `주민등록등본_최근5년포함_정상샘플.txt`)을 직접 업로드하여 실시간 검수도 가능합니다.
4. **[Step 4] 신청서·계획서 자동 기입 & 제출용 완제품 패키징 (`Action 완주`)**
   * **시연 포인트**: 서류 OCR 추출값으로 신청서 빈칸을 자동 완성하고, 심사 금칙어를 회피한 활용계획서/구직활동계획서 초안 생성 및 파일명 규격화 패키지를 원클릭 다운로드합니다.
